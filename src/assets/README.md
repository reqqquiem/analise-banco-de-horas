# Identidade visual fornecida pelo usuário

Os arquivos SVG foram extraídos sem alteração do PPT `Repositorio_ICONOS_DIC'24.pptx` anexado pelo usuário:

- `naturgy-branco.svg`: `ppt/media/image2.svg`.
- `naturgy-azul.svg`: `ppt/media/image6.svg`.
- `pagamento.svg`: `ppt/media/image46.svg`.
- `calendario.svg`: `ppt/media/image58.svg`.
- `tempo.svg`: `ppt/media/image62.svg`.

O tema dos três PPTs acessíveis informa azul `#004570`, laranja `#FF7200` e fundo `#F4F3EF`; formas e ícones também usam `#FF7300` e `#004571`. A interface usa azul `#004570` e laranja `#FF7300`. Os PPTs citam a família FS Emeric, mas não fornecem arquivos de fonte utilizáveis; a interface prevê essa família quando instalada, com DM Sans/Arial como alternativas.

O material de ilustrações excede o limite de transferência de 32 MiB e não foi utilizado. Os arquivos PPT não fazem parte do repositório.
